# Sabrina Joias - Blog

Um blog minimalista e elegante dedicado a moda, tendências e sustentabilidade no mercado de semijoias.

## 🎨 Design

- **Paleta de Cores**: Preto, Branco e Amarelo
- **Estilo**: Minimalista e moderno
- **Responsivo**: Totalmente adaptável a dispositivos móveis
- **Performance**: Otimizado para carregamento rápido

## 📁 Estrutura do Projeto

```
sabrina-blog/
├── index.html           # Página inicial do blog
├── styles.css           # Estilos principais
├── post-styles.css      # Estilos para páginas de artigos
├── README.md            # Este arquivo
├── posts/               # Diretório com páginas de artigos
│   ├── post-1.html
│   ├── post-2.html
│   ├── post-3.html
│   └── post-4.html
└── images/              # Diretório com imagens do blog
    ├── post-1.jpg
    ├── post-2.jpg
    ├── post-3.jpg
    └── post-4.jpg
```

## 🚀 Como Usar

### 1. Clonar o Repositório

```bash
git clone https://github.com/sabrinanovoauto/blog.git
cd blog
```

### 2. Adicionar Imagens

Coloque as imagens dos artigos no diretório `images/`:
- `post-1.jpg` - Sabrina Joias: Uma história de Qualidade, Design e Emoção
- `post-2.jpg` - Tendências de Semijoias para 2025
- `post-3.jpg` - A Evolução do Mercado de Semijoias no Brasil
- `post-4.jpg` - Diferença entre Semijoia Banhada e Folheada

### 3. Editar Conteúdo

#### Página Inicial (`index.html`)
- Edite o título, descrição e links de navegação
- Atualize as informações dos artigos no grid

#### Páginas de Artigos (`posts/post-*.html`)
- Edite o conteúdo do artigo na seção `.post-body`
- Atualize o título, data e autor do artigo

### 4. Personalizar Estilos

Edite `styles.css` e `post-styles.css` para:
- Alterar cores (variáveis CSS no topo)
- Ajustar tipografia
- Modificar espaçamento e layout

## 🎯 Customização

### Alterar Cores

No arquivo `styles.css`, modifique as variáveis CSS:

```css
:root {
    --primary-black: #1a1a1a;      /* Cor preta principal */
    --primary-white: #ffffff;      /* Cor branca principal */
    --bg-yellow: #fef5e7;          /* Cor de fundo amarelada */
    --accent-gray: #e8e8e8;        /* Cinza de acentuação */
    --text-gray: #666666;          /* Cinza do texto */
    --text-light-gray: #999999;    /* Cinza claro */
    --border-color: #d0d0d0;       /* Cor das bordas */
}
```

### Adicionar Novos Artigos

1. Crie um novo arquivo `posts/post-X.html` baseado em `post-1.html`
2. Adicione um novo card na página inicial (`index.html`)
3. Coloque a imagem correspondente em `images/post-X.jpg`
